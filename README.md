# Football Performance Analytics Dashboard | Power BI

## Project Overview

The **Football Performance Analytics Dashboard** is an interactive Power BI solution designed to analyze player and team performance using advanced football statistics. The dashboard transforms raw match data into actionable insights for coaches, analysts, scouts and decision-makers through intuitive visualizations and performance metrics.

This project demonstrates the use of **Power BI**, **Power Query**, **DAX** and data visualization best practices to build a professional, multi-page analytics dashboard.

---

## Objectives

* Analyze individual player performance across multiple metrics.
* Compare team performance throughout the tournament.
* Identify top-performing players and clubs.
* Evaluate offensive, defensive, tactical, and physical contributions.
* Explore player market value relative to on-field performance.
* Build an executive dashboard for quick decision-making.
